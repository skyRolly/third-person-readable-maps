# Installed-client smoke test: Minecraft 1.14.4

The intermediary JAR built from implementation commit
`bfa85625b10a2709fc01af26eef9e80df791dcb9` had SHA-256
`909b2299eed92d71c054bc9ddb4829235f560c657fab79a60f91a78354a06eec`.
It was installed with Fabric Loader 0.20.1, Java 8 (8.0.504+1), Linux and a
software Xorg/Mesa display. The client launched, applied its required Mixin,
joined a local single-player world and [displayed terrain on a main-hand map
in third person](1.14.4-terrain.png). The map data was produced in the world.

This is a partial smoke test. It does not verify other 1.14 versions, the full
hand and arm layout, lighting and OpenGL state restoration, missing map data,
movement, first-person regressions, multiplayer, or independent visual
acceptance. The software display reported an unavailable audio device and the
offline client could not retrieve online profile data. Complete the full
runtime matrix on the final artifact before release.
