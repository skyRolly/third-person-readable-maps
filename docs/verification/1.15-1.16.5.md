# Installed-client smoke tests: Minecraft 1.15 and 1.16.5

The same intermediary JAR built from implementation commit
`84dde45175c0ca154b44a1acd4efe30d741d5077` had SHA-256
`d30a2a682699e881903275ce373d79374b1475e5dff10e7b3e66d364819b13de`.
It was installed with Fabric Loader 0.20.1, Java 8 (8.0.504+1), Linux and a
software Xorg/Mesa display in both versions. Each client applied its required
Mixin, joined the same local single-player world, and displayed terrain on a
main-hand map in third person: [1.15](1.15-terrain.png) and
[1.16.5](1.16.5-terrain.png).

These are partial smoke tests. The other seven versions, hand and arm layout,
lighting, missing data, movement, first-person regressions, multiplayer and
independent visual acceptance remain outstanding. The software display had no
audio device and the offline client could not retrieve online profile data.
Complete the full runtime matrix on the final artifact before release.
