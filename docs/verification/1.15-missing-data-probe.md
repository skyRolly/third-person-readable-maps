# 1.15–1.16.5 forced missing-data diagnostic

The ordinary untagged-map smoke does not establish missing data: old clients can
resolve an absent map ID to map 0, and a server can create map state during
inventory ticks. This separate fault-injection test redirects only the map-state
lookup inside the installed candidate renderer to return `null`. It does not
simulate all ways a map state can be absent.

The installed distributable was the unchanged Java 8 candidate JAR with SHA-256
`d30a2a682699e881903275ce373d79374b1475e5dff10e7b3e66d364819b13de`. A second, test-only diagnostic mod used Fabric Loader
0.20.1, Java 8 and Linux software rendering; it is not part of the distributable.
Its JAR SHA-256 was `4436a8f77c2633a2985807bf4721a39a298fe31b824da85270a59d0f9ecfc987`. The exact
[probe source](missing-probe/MissingDataProbeMixin.java), [mod metadata](missing-probe/fabric.mod.json),
and [Mixin config](missing-probe/missing-data-probe.mixins.json) are retained.

## 1.15 forced-null draw

The test-only helper returned `null` for eight map-state lookups and recorded
eight completed draws. The client saved and exited without a Mixin or linkage
error; see the [log excerpt](missing-probe/1.15-probe-excerpt.txt). The
[screenshot](missing-probe/1.15-forced-null.png) shows the unfilled left-hand
map face with nearby scenery partly obscuring it. This is one injected null path in
one pose, not an ordinary missing-data or full graphical acceptance test.

## 1.15 unavailable client map state after withheld updates

In a separate installed-client profile, a [test-only helper](unavailable-probe/WithholdMapUpdateMixin.java)
withheld map-update packets. An [observer](unavailable-probe/ObserveMapStateMixin.java)
called the game's actual map-state lookup and returned its result unchanged. The
[log](unavailable-probe/1.15-unavailable-excerpt.txt) records withheld updates,
an actual `null` lookup and completed map draws; the client saved and exited
without a Mixin or linkage error. The unchanged candidate JAR SHA-256 was
`d30a2a682699e881903275ce373d79374b1475e5dff10e7b3e66d364819b13de`; the separate helper JAR SHA-256 was `60fb6cf2305d8045905b57313c6581f56899957265e2cf5a22a1ec9fb6dab27d`.
Its [mod metadata](unavailable-probe/fabric.mod.json) and [Mixin config](unavailable-probe/unavailable-map-probe.mixins.json)
are retained. The [screenshot](unavailable-probe/1.15-unavailable.png)
shows the unfilled left-hand face, partly obscured by nearby scenery. This is
one local layout with intentionally withheld updates, not remote multiplayer or
complete missing-data acceptance.
