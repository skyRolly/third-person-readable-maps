# Installed-client smoke tests: Minecraft 1.17 and 1.19.2

The identical intermediary JAR built from implementation commit
`a12c56cc742ec0b0c3ab26619bddf110482b95d6` had SHA-256
`aee00518a1a5b3c31cf794063ac685aa2675ac0b719f11d2b50d0ec8ccf351e6`.
It was installed with Fabric Loader 0.20.1, Linux and software Xorg/Mesa.
Minecraft 1.17 used Java 16 (16.0.2+7); 1.19.2 used Java 17 (17.0.21+9).
