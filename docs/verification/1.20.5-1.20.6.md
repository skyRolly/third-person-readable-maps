# Candidate verification: Minecraft 1.20.5 and 1.20.6

This is partial smoke testing, not release acceptance. Source commit
`32164d846089ce67d5c0a10ba351796207312b02` produced the unchanged JAR
installed on both clients, SHA-256
`8c02fa2fc1b565e8154926642ac4fa260b28f59aeca8a49f9958a8d39050cdfd`.

Environment: Linux x86-64, Debian OpenJDK 21.0.12.1, Fabric Loader 0.20.1,
Xorg dummy display with Mesa software GL, offline local single-player creative
world. The world was created on 1.20.5 and opened on 1.20.6. Account/Realms
services and an audio device were unavailable. This does not test multiplayer
or a hardware GPU.

| Check | 1.20.5 | 1.20.6 |
|---|---|---|
| Required Mixin descriptor, 26 classes, 43 game and 2 JOML references | PASS | PASS |
| Installed JAR: client startup, local world and Mixin application | PASS | PASS |
| Third-person main-hand map terrain | Observed | Observed |
| Off hand and both hands | Observed (see additional smoke tests below) | Observed (see additional smoke tests below) |
| Left-handed, opposite-stone and missing-data smoke | Observed (see below) | Observed (see below) |
| Movement, lighting and complete first-person regression | NOT RUN | NOT RUN |

The verifier used SHA-1-checked official clients and metadata-declared JOML

## Additional 1.20.5 left-handed and first-person checks

With the same candidate JAR, the left-handed local client displayed terrain in
the [main hand](1.20.5-extra-left-main.png), [off hand](1.20.5-extra-left-off.png),
and [both hands](1.20.5-extra-left-both.png). Terrain remained visible with stone
in the opposite hand for the [main-hand map](1.20.5-extra-left-main-stone.png)
and [off-hand map](1.20.5-extra-left-off-stone.png). A filled map without map
data showed a [blank face](1.20.5-extra-left-missing.png); the client remained
running.

The [candidate first-person view](1.20.5-extra-firstperson.png) was compared
with the same Fabric Loader profile [without the candidate JAR](1.20.5-extra-firstperson-no-mod.png)
using a copy of the saved world. In the 540 by 440 pixel map crop at `(370, 60)`
the mean absolute channel difference was 1.045 on a 0–255 scale;
98.269% of pixels differed by at most 10 levels per channel,
with a maximum of 17. The views were not pixel-identical, and this single
comparison does not establish complete first-person regression coverage.

## Unsupported-version launch

A headless Linux Fabric Loader 0.20.1 launch installed this same JAR into a
Minecraft 1.21.1 client using Java 21. Fabric exited with status 1 during mod
resolution and explicitly identified 1.21.1 as unsupported; Mixin initialization
was not reached. The [launch log](1.21.1-unsupported-neighbor.txt) records the
actual rejection. This checks the declared version guard for that client, not
a forced installation with the guard bypassed.

## Additional incompatible client or Java launches

Headless Linux launches installed the same candidate JAR with Fabric Loader
0.20.1. Each exited with status 1 during mod resolution before Mixin
initialization. The retained logs show these rejected environments:

- [Minecraft 1.21 with Java 21, because the candidate permits only 1.20.5 and 1.20.6](1.21-unsupported-neighbor.txt).
- [Minecraft 1.20.6 with Java 17, because the mod requires Java 21 or later](1.20.6-java17-rejected.txt).

These checks cover the listed combinations and do not exercise a forced
installation with the metadata guard bypassed.
