# Installed-client smoke tests: Minecraft 1.19.4–1.20.4

The unchanged intermediary JAR built from implementation commit
`532cfb548bb29eb99fbcb57424592f07c8ca3606` had SHA-256
`7b6e18ebce73045fb937640a1edc0b364a6b13f6bb66941f0c209a204cab0af9`.
It was installed with Fabric Loader 0.20.1, Java 17 (17.0.21+9), Linux, and
software Xorg/Mesa in every version below. Each client applied its required
Mixin, joined a local single-player creative world and displayed generated
map terrain in these arrangements. The same test world was upgraded across
the six clients; its daylight cycle was disabled for clear screenshots.

These are partial local-player smoke tests. The additional per-version
left-handed, opposite-hand, missing-data and first-person comparisons are
listed below; unlisted versions and cases remain NOT RUN. Complete lighting,
movement and first-person regression, multiplayer and independent visual
acceptance remain outstanding. The software display had no audio device and
the offline clients could not retrieve online profiles. Complete the full
runtime matrix on the final artifact before release.

## Unsupported-version launch

A headless Linux Fabric Loader 0.20.1 launch installed this same JAR into a
Minecraft 1.19.3 client using Java 17. Fabric exited with status 1 during mod
resolution and explicitly identified 1.19.3 as unsupported; Mixin initialization
was not reached. The [launch log](1.19.3-unsupported-neighbor.txt) records the
actual rejection. This checks the declared version guard for that client, not
a forced installation with the guard bypassed. A wrong-Java launch is recorded below.

The initial 1.19.4 first-person capture used a fixture map without a saved
map ID and showed [blank parchment](1.19.4-firstperson-fixture-blank.png). The
fixture was corrected to select saved map 2 and all checks below were repeated;
the initial image is not counted as terrain evidence.

## Additional 1.19.4 left-handed and first-person checks

With the same candidate JAR, the left-handed local client displayed terrain in
the [main hand](1.19.4-extra-left-main.png), [off hand](1.19.4-extra-left-off.png),
and [both hands](1.19.4-extra-left-both.png). Terrain remained visible with stone
in the opposite hand for the [main-hand map](1.19.4-extra-left-main-stone.png)
and [off-hand map](1.19.4-extra-left-off-stone.png). A filled map without map
data showed a [blank face](1.19.4-extra-left-missing.png); the client remained
running.

The [candidate first-person view](1.19.4-extra-firstperson.png) was compared
with the same Fabric Loader profile [without the candidate JAR](1.19.4-extra-firstperson-no-mod.png)
using a copy of the saved world. In the 540 by 440 pixel map crop at `(370, 60)`
the mean absolute channel difference was 0.831 on a 0–255 scale;
99.465% of pixels differed by at most 10 levels per channel,
with a maximum of 13. The views were not pixel-identical, and this single
comparison does not establish complete first-person regression coverage.
