# Final 1.0.0 numeric map identity and render-state probes

On Minecraft 1.14 with Fabric Loader 0.20.1, Java 8 and Linux Xorg/Mesa software rendering, controlled copied-stack tests compared the earlier 1.0.0 JAR `5770c22a021f1c2fd74a80444fe759701f70c82a65fa03e9fd5e90154e701423` with the corrected JAR `e9ee5d9e7cd0c3e2bbbab8f328bf824e10388fa7049902e165e0c7684b39972b`. The world contained distinguishable map-zero and map-two data. The [test-only probe](numeric-mapid-1.0.0/MapIdProbeMixin.java) was installed separately (probe JAR SHA-256 `1a7d25d11a605766b86818afd2ecfa8572a7fd8a8cb09216949f430af217b049`); it substituted copies and observed the real game lookup without changing the actual inventory stack.

| Identity | Earlier 1.0.0 candidate | Corrected 1.0.0 candidate |
|---|---|---|
| Absent tag, empty tag or text value | No lookup | No lookup |
| Fractional `0.5`, overflowing long `4294967296`, or NaN | Lookup returned map-zero data | No lookup |
| Explicit integer zero or short zero | Lookup returned map-zero data | Lookup returned map-zero data |
| Explicit integer map 2 | Lookup returned map-two data | Lookup returned map-two data |
| Valid but unavailable map 9999 | Lookup returned no data | Lookup returned no data |

Each case ran three times; the [earlier](numeric-mapid-1.0.0/old-excerpt.txt) and [corrected](numeric-mapid-1.0.0/fixed-excerpt.txt) excerpts, [scene](numeric-mapid-1.0.0/fixed-scene.png), [metadata](numeric-mapid-1.0.0/fabric.mod.json), [Mixin configuration](numeric-mapid-1.0.0/mapid-probe.mixins.json) and [local harness](numeric-mapid-1.0.0/run.py) are retained. The guard permits integral values representable as a Java integer, including zero, without mutating the stack.

The same final JAR was also installed with the [two-texture-unit state probe](state-units-1.0.0/StateProbeMixin.java) (probe JAR SHA-256 `d83161521eeaf76913473d8167fa1a7fd6e8c44aca6f74bb197e5e4b1d338581`). Across eight actual draws it preserved the active texture unit, seeded binding and alternating incoming lighting; see the [excerpt](state-final-1.0.0/fixed-excerpt.txt), [scene](state-final-1.0.0/fixed-scene.png) and [harness](state-final-1.0.0/run.py). The [earlier state comparison](1.0.0-state-probe.md) documents the original texture leak but used an earlier artifact.

These are targeted diagnostics for one game version and scene. They do not establish all hand layouts, exception paths, naturally delayed map data, subsequent entity rendering, hardware-GPU behavior, multiplayer, or independent visual acceptance.
