# Candidate verification: Minecraft 1.21.2 and 1.21.3

This is partial smoke testing, not release acceptance. Implementation source
commit `84d8291e16fc14ffa3b0956404b64c9538251693` produced the unchanged JAR
installed on both clients, SHA-256
`28a15aacf531dfdb3dd51ba63b7e9cf42000e0b981d863cdc0c27bebc89523e4`.

Environment: Linux x86-64, Debian OpenJDK 21.0.12.1, Fabric Loader 0.20.1,
Xorg dummy display with Mesa software GL, offline local single-player creative
world. The world was created on 1.21.2 and opened on 1.21.3. Account/Realms
services and an audio device were unavailable. This does not test multiplayer
or a hardware GPU.

| Check | 1.21.2 | 1.21.3 |
|---|---|---|
| Required Mixin descriptor, 27 classes, 43 game and 2 JOML references | PASS | PASS |
| Installed JAR: client startup, local world and Mixin application | PASS | PASS |
| Third-person main-hand map terrain | Observed | Observed |
| Off hand, both hands, occupied opposite hand, left-handed layout, movement, missing data and first-person regression | NOT RUN | NOT RUN |
| Remote-player multiplayer and independent visual acceptance | NOT RUN | NOT RUN |

The verifier used SHA-1-checked official client artifacts and the JOML 1.10.5
specified by each version. It rejected the neighboring 1.21.4 Mixin descriptor;
wrong-Java and unsupported-neighbor installed-client checks were not run.
[1.21.2 screenshot](1.21.2-terrain.png) and
[1.21.3 screenshot](1.21.3-terrain.png) show one camera angle, not full
functional acceptance. Candidate OSV findings and review/protection gates
remain unresolved.
