# Candidate verification: Minecraft 1.21.2 and 1.21.3

This is partial smoke testing, not release acceptance. Implementation source
commit `84d8291e16fc14ffa3b0956404b64c9538251693` produced the unchanged JAR
installed on both clients, SHA-256
`28a15aacf531dfdb3dd51ba63b7e9cf42000e0b981d863cdc0c27bebc89523e4`.

Environment: Linux x86-64, Debian OpenJDK 21.0.12.1, Fabric Loader 0.20.1,
Xorg dummy display with Mesa software GL, offline local single-player creative
world. The world was created on 1.21.2 and opened on 1.21.3. Account/Realms
services and an audio device were unavailable. This does not test multiplayer
or a hardware GPU.

| Check | 1.21.2 | 1.21.3 |
|---|---|---|
| Required Mixin descriptor, 27 classes, 43 game and 2 JOML references | PASS | PASS |
| Installed JAR: client startup, local world and Mixin application | PASS | PASS |
| Third-person main-hand map terrain | Observed | Observed |
| Off hand and both hands | Observed (see additional smoke tests below) | Observed (see additional smoke tests below) |
| Left-handed, opposite-stone and missing-data smoke | Observed (see below) | Observed (see below) |
| Movement, lighting and complete first-person regression | NOT RUN | NOT RUN |
| Remote-player multiplayer and independent visual acceptance | NOT RUN | NOT RUN |

The verifier used SHA-1-checked official client artifacts and the JOML 1.10.5
specified by each version. It rejected the neighboring 1.21.4 Mixin descriptor.
A wrong-Java launch is recorded below; unsupported-neighbor installed-client
checks were not run.

functional acceptance. Candidate OSV findings and review/protection gates
remain unresolved.

## Additional 1.21.2 left-handed and first-person checks

With the same candidate JAR, the left-handed local client displayed terrain in
the [main hand](1.21.2-extra-left-main.png), [off hand](1.21.2-extra-left-off.png),
and [both hands](1.21.2-extra-left-both.png). Terrain remained visible with stone
in the opposite hand for the [main-hand map](1.21.2-extra-left-main-stone.png)
and [off-hand map](1.21.2-extra-left-off-stone.png). A filled map without map
data showed a [blank face](1.21.2-extra-left-missing.png); the client remained
running.

The [candidate first-person view](1.21.2-extra-firstperson.png) was compared
with the same Fabric Loader profile [without the candidate JAR](1.21.2-extra-firstperson-no-mod.png)
using a copy of the saved world. In the 540 by 440 pixel map crop at `(370, 60)`
the mean absolute channel difference was 0.996 on a 0–255 scale;
98.481% of pixels differed by at most 10 levels per channel,
with a maximum of 16. The views were not pixel-identical, and this single
comparison does not establish complete first-person regression coverage.

## Wrong-Java launch

A headless Linux Fabric Loader 0.20.1 launch installed this same JAR into a
Minecraft 1.21.2 client using Java 17. Fabric exited with status 1 during mod
resolution and explicitly reported that the mod requires Java 21 or later;
Mixin initialization was not reached. See the [launch log](1.21.2-java17-rejected.txt).
This checks rejection of Java 17 for one client and does not cover every
unsupported runtime.
