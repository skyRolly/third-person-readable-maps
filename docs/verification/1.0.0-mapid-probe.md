# Minecraft 1.15 map identity probe

**Historical candidate evidence:** this record's 1.0.0 JAR predates the later numeric-identity guard and does not certify the final artifact. Its original artifact hashes and observations are preserved below.


Minecraft 1.15's `MapItem.getMapId` returns zero when the `map` tag is absent
or not numeric. Its `getSavedData` then looks up map zero. The previous
`0.0.2` candidate called that lookup without checking for an explicit ID.

The unchanged previous JAR (`d30a2a682699e881903275ce373d79374b1475e5dff10e7b3e66d364819b13de`)
and the earlier `1.0.0` candidate's JAR (`2f8b094db2de01569e42605870ef05a82880ffc72291796ded0a8dd518804eed`)
were installed separately on Minecraft 1.15 with Fabric Loader 0.20.1 and Java 8
on Linux Xorg/Mesa software rendering. The copied world contained map-zero and
nonzero data. A [test-only Mixin](mapid-1.0.0/MapIdProbeMixin.java) substituted
copies of the held stack at the map renderer's entry, leaving the real inventory
item unchanged. It observed calls and return values from the real game lookup.
The probe JAR SHA-256 was
`162eeb37e356d5f47936f0eb01bbaa267adafd73d5c0bde5fbd321b9ccca9c62`;
its [metadata](mapid-1.0.0/fabric.mod.json), [Mixin configuration](mapid-1.0.0/mapid-probe.mixins.json)
and [local harness](mapid-1.0.0/run.py) are retained.

| Copied item identity | Previous JAR | New JAR |
|---|---|---|
| Absent tag, empty tag, or nonnumeric `map` | Lookup called and returned map-zero data | Lookup not called; no data used |
| Explicit map zero | Lookup called; data returned | Lookup called; data returned |
| Explicit nonzero map 2 | Lookup called; data returned | Lookup called; data returned |
| Explicit unavailable map 9999 | Lookup called; no data returned | Lookup called; no data returned |

Each case ran three times; see the [previous](mapid-1.0.0/old-excerpt.txt)
and [new](mapid-1.0.0/fixed-excerpt.txt) logs and the [new scene](mapid-1.0.0/fixed-scene.png).
Both clients saved and exited. This controlled substituted-stack diagnostic
does not replace natural multiplayer missing-update or full visual acceptance.
The remaining eight versions in this group require final-artifact runtime checks.
