# Candidate verification: Minecraft 1.21.9 and 1.21.10

This is a smoke-test record, not release acceptance. The implementation source
was commit `ee07f9599f3868909c1d198802783422f6d83e72`; a clean build of that
commit reproduced the same installed JAR on Linux. The screenshots were taken
with that unchanged JAR, SHA-256
`03c760850ef7b1501fb5b6d23af61ce855e746ab8d5a2f2a1deed9a4480e26ac`.

Environment: Linux x86-64, Debian OpenJDK 21.0.12.1, Fabric Loader 0.20.1,
Xorg dummy display with Mesa software GL, offline local single-player creative
world. The local client could not reach Minecraft account/Realms services and
had no audio device; X11 reported a standard-cursor-shape warning. These are
not results for multiplayer or a hardware GPU.

| Check | 1.21.9 | 1.21.10 |
|---|---|---|
| Same installed JAR; client reached menu and loaded world | PASS | PASS |
| Both required Mixins applied sufficiently to enter a world and render held maps | PASS | PASS |
| SHA-1-checked client: 2 Mixin descriptors, 27 classes, 39 referenced members | PASS | PASS |
| Third-person map terrain | Observed in main and off hand | Observed; left-handed setting |
| Two maps held | Seen; complete alignment not independently assessed | Both back faces seen; terrain on one side observed |
| Missing map ID/data | Blank face, no crash | Blank face, no crash |
| First-person map contents | Observed | Observed |
| Moving arms, every occupied-hand combination and complete left/right layout | NOT RUN completely | NOT RUN completely |
| Remote-player multiplayer rendering | NOT RUN | NOT RUN |
| Independent human visual review and installed-client testing on hardware GPU | NOT RUN | NOT RUN |

Fabric Loader rejected the candidate on 1.21.8 before game startup; the
cross-version verifier also rejected both adjacent 1.21.8 and 1.21.11 Mixin
descriptors. No wrong-Java runtime was launched. The metadata and bytecode
require Java 21, checked during the build.
