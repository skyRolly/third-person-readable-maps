# Candidate verification: Minecraft 1.21.9 and 1.21.10

This is a smoke-test record, not release acceptance. The implementation source
was commit `ee07f9599f3868909c1d198802783422f6d83e72`; a clean build of that
commit reproduced the same installed JAR on Linux. The screenshots were taken
with that unchanged JAR, SHA-256
`03c760850ef7b1501fb5b6d23af61ce855e746ab8d5a2f2a1deed9a4480e26ac`.

Environment: Linux x86-64, Debian OpenJDK 21.0.12.1, Fabric Loader 0.20.1,
Xorg dummy display with Mesa software GL, offline local single-player creative
world. The local client could not reach Minecraft account/Realms services and
had no audio device; X11 reported a standard-cursor-shape warning. These are
not results for multiplayer or a hardware GPU.

| Check | 1.21.9 | 1.21.10 |
|---|---|---|
| Same installed JAR; client reached menu and loaded world | PASS | PASS |
| Both required Mixins applied sufficiently to enter a world and render held maps | PASS | PASS |
| SHA-1-checked client: 2 Mixin descriptors, 27 classes, 39 referenced members | PASS | PASS |
| Third-person map terrain | Observed in main and off hand | Observed; left-handed setting |
| Two maps held | Seen; complete alignment not independently assessed | Both back faces seen; terrain on one side observed |
| Missing map ID/data | Blank face, no crash | Blank face, no crash |
| First-person map contents | Observed | Observed |
| Moving arms, every occupied-hand combination and complete left/right layout | NOT RUN completely | NOT RUN completely |
| Remote-player multiplayer rendering | NOT RUN | NOT RUN |
| Independent human visual review and installed-client testing on hardware GPU | NOT RUN | NOT RUN |

Fabric Loader rejected the candidate on 1.21.8 before game startup; the
cross-version verifier also rejected both adjacent 1.21.8 and 1.21.11 Mixin
descriptors. No wrong-Java runtime was launched. The metadata and bytecode
require Java 21, checked during the build.

## Additional 1.21.10 left-handed and first-person checks

With the same candidate JAR, the left-handed local client displayed terrain in
the [main hand](1.21.10-extra-left-main.png), [off hand](1.21.10-extra-left-off.png),
and [both hands](1.21.10-extra-left-both.png). Terrain remained visible with stone
in the opposite hand for the [main-hand map](1.21.10-extra-left-main-stone.png)
and [off-hand map](1.21.10-extra-left-off-stone.png). A filled map without map
data showed a [blank face](1.21.10-extra-left-missing.png); the client remained
running.

The [candidate first-person view](1.21.10-extra-firstperson.png) was compared
with the same Fabric Loader profile [without the candidate JAR](1.21.10-extra-firstperson-no-mod.png)
using a copy of the saved world. In the 540 by 440 pixel map crop at `(370, 60)`
the mean absolute channel difference was 0.569 on a 0–255 scale;
100.000% of pixels differed by at most 10 levels per channel,
with a maximum of 10. The views were not pixel-identical, and this single
comparison does not establish complete first-person regression coverage.

## Additional 1.21.9 left-handed and first-person checks

With the same candidate JAR, the left-handed local client displayed terrain in
the [main hand](1.21.9-extra-left-main.png), [off hand](1.21.9-extra-left-off.png),
and [both hands](1.21.9-extra-left-both.png). Terrain remained visible with stone
in the opposite hand for the [main-hand map](1.21.9-extra-left-main-stone.png)
and [off-hand map](1.21.9-extra-left-off-stone.png). A filled map without map
data showed a [blank face](1.21.9-extra-left-missing.png); the client remained
running.

The [candidate first-person view](1.21.9-extra-firstperson.png) was compared
with the same Fabric Loader profile [without the candidate JAR](1.21.9-extra-firstperson-no-mod.png)
using a copy of the saved world. In the 540 by 440 pixel map crop at `(370, 60)`
the mean absolute channel difference was 0.537 on a 0–255 scale;
100.000% of pixels differed by at most 10 levels per channel,
with a maximum of 9. The views were not pixel-identical, and this single
comparison does not establish complete first-person regression coverage.

The first [candidate](1.21.9-extra-firstperson-uncontrolled.png) and
[no-mod](1.21.9-extra-firstperson-uncontrolled-no-mod.png) captures had
different surroundings after the player settled; their map-crop mean channel
difference was 11.199 with a maximum of 46. That pair was inconclusive. The
comparison above was repeated from separate copies of a saved world with the
player at `(5.5, 81.0, -62.5)` before and after each run. Both captures used
that stable position; the controlled views still are not pixel-identical.

## Repeated unsupported-version launch

A headless Linux Fabric Loader 0.20.1 launch installed this same JAR into a
Minecraft 1.21.8 client using Java 21. An initial repeat was inconclusive because
the cached client JAR was missing; after restoring the official client and
checking its SHA-1, Fabric exited with status 1 during mod resolution and
identified 1.21.8 as unsupported. Mixin initialization was not reached. The
[launch log](1.21.8-unsupported-neighbor.txt) records the successful rejection.
This checks the declared version guard, not a forced installation with it bypassed.
