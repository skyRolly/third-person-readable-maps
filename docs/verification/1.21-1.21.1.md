# Candidate verification: Minecraft 1.21 and 1.21.1

This is partial smoke testing, not release acceptance. Source commit
`5f5fdad012ab499b2f31e0f878d507c4d774d4b4` produced the unchanged JAR
installed on both clients, SHA-256
`d4054952d77a3b4dc79d7681779126cf38bd0fb34c1f9afd3346ceb9f4ca4745`.

Environment: Linux x86-64, Debian OpenJDK 21.0.12.1, Fabric Loader 0.20.1,
Xorg dummy display with Mesa software GL, offline local single-player creative
world. The world was created on 1.21 and opened on 1.21.1. Account/Realms
services and an audio device were unavailable. This does not test multiplayer
or a hardware GPU.

| Check | 1.21 | 1.21.1 |
|---|---|---|
| Required Mixin descriptor, 26 classes, 42 game and 2 JOML references | PASS | PASS |
| Installed JAR: client startup, local world and Mixin application | PASS | PASS |
| Third-person main-hand map terrain | Observed | Observed |
| Off hand and both hands | Observed (see additional smoke tests below) | Observed (see additional smoke tests below) |
| Left-handed, opposite-stone and missing-data smoke | Observed (see below) | Observed (see below) |
| Movement, lighting and complete first-person regression | NOT RUN | NOT RUN |
| Remote-player multiplayer and independent visual acceptance | NOT RUN | NOT RUN |

The verifier used SHA-1-checked official clients and metadata-declared JOML
1.10.5. On neighboring 1.20.6 it found incompatible resource-location and
vertex-consumer member references; wrong-Java and unsupported-neighbor
installed-client tests were not run.

functional acceptance. Candidate security findings and review/protection gates
remain unresolved.

## Additional 1.21 left-handed and first-person checks

With the same candidate JAR, the left-handed local client displayed terrain in
the [main hand](1.21-extra-left-main.png), [off hand](1.21-extra-left-off.png),
and [both hands](1.21-extra-left-both.png). Terrain remained visible with stone
in the opposite hand for the [main-hand map](1.21-extra-left-main-stone.png)
and [off-hand map](1.21-extra-left-off-stone.png). A filled map without map
data showed a [blank face](1.21-extra-left-missing.png); the client remained
running.

The [candidate first-person view](1.21-extra-firstperson.png) was compared
with the same Fabric Loader profile [without the candidate JAR](1.21-extra-firstperson-no-mod.png)
using a copy of the saved world. In the 540 by 440 pixel map crop at `(370, 60)`
the mean absolute channel difference was 0.880 on a 0–255 scale;
99.320% of pixels differed by at most 10 levels per channel,
with a maximum of 14. The views were not pixel-identical, and this single
comparison does not establish complete first-person regression coverage.
