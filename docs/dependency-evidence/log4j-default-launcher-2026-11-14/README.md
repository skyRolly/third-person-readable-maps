# Historical-game logging configuration and critical advisory triage

The [metadata survey](metadata-index.json) verified Mojang metadata SHA-1 values and the referenced logging-file size and SHA-1 for all 18 candidate runtime versions whose inventories include the reviewed critical Log4j matches. Every surveyed manifest selects [client-1.12.xml](client-1.12.xml), SHA-1 `bd65e7d2e3c237be76cfbef4c2405033d7f91521`, via `-Dlog4j.configurationFile=${path}`. The retained [collector](collect.py) records the exact URLs and checks.

The file appender uses `%msg{nolookups}`; the console uses Mojang's `LegacyXMLLayout`. This establishes a default launcher configuration, not the effective configuration of every launcher, server or installed Mod, and does not trace the custom layout or all untrusted input paths. In particular the CVE-2021-45046 advisory says message-lookup configuration alone is not a complete mitigation. These observations do not establish non-applicability or authorize release.

The [critical disposition record](critical-dispositions.json) advances 18 candidate occurrences to **Upstream-dependent remediation**, with reachability still under investigation and each scanner finding still failing. It retains the previous source-bound inventory identity and separately names the current proposed source; the intervening changes do not alter game sources, Gradle build inputs or dependency declarations. This continuity observation is not a fresh exact-source dependency snapshot. The affected Log4j and Netty libraries are game-managed; a compatible upstream fix or a separately reviewed alternative is needed if the vulnerable path is applicable. No Mod-imposed runtime library override or risk acceptance is proposed.

GHSA-jfh8-c2jp-5v3q (CVE-2021-44228), GHSA-7rjr-3q55-vv33 (CVE-2021-45046), and GHSA-fxph-q3j8-mv87 (CVE-2017-5645) are tracked separately. The Netty GHSA-c4c3-7fpv-j4q5 recommendations retain their [previous advisory evidence](../ghsa-c4c3-2026-11-14.json). All 18 remain subject to independent security review.
